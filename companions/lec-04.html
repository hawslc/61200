Tic-tac-toe is a state machine

The 8-puzzle gets the lecture. Here is the same apparatus — states, transitions, a preserved predicate, a derived variable — on a game you already know the rules of, so the only new thing is the machinery.

1

A state is the whole board, not the last move

The temptation is to call “X plays the centre” a state. It isn’t — it’s a transition. A state has to carry everything the next transition needs to know, and that means the full board and whose turn it is.

state a pair s = (b, p). The board b is a 3×3 tuple whose entries are X, O, or – (empty), and p ∈ {X, O} is the player who moves next. For example, s = ( X–––O–––X , O ) q₀ ( ––––––––– , X ) — the empty board, X to move. s ↦ t if nobody has three in a row, p writes its mark in any empty cell and the turn passes to the other player. If somebody has three in a row, there are no transitions.

So a state is just the board plus whose turn it is. Some pairs, like a board of nine X’s, can never come up in play — telling those apart is §2’s job.

That last clause is the whole design. Winning doesn’t trigger anything; it just leaves you in a state with no outgoing transitions — a final state. A play that reaches a final state has terminated.

2

An invariant rules boards out, never in

Here is the predicate. For a state s = (b, p), write #X and #O for the number of each mark on b:

P(s) (#X = #O  ∧  p = X)  ∨  (#X = #O + 1  ∧  p = O)

P is preserved. Suppose P(s) and s ↦ t. Either p = X, in which case #X = #O and the transition writes one X and hands the turn to O, giving #X = #O + 1 with p = O — the second disjunct. Or p = O, in which case #X = #O + 1 and the transition writes one O and hands back, giving #X = #O with p = X — the first disjunct. Either way P(t).

And P(q₀) holds: 0 = 0 and p = X. So by the Invariant Principle, P is an invariant — true at every reachable state. Which gives you the thing invariants are for: any state where P fails is unreachable, and you never had to search.

Try it

Four boards. Decide before you click — and where a board is reachable, trace the play that gets there.

The asymmetry is the point. An invariant can only ever prove unreachability. When P fails, you are done — no reachable state looks like that. When P holds, you have learned nothing: the third board above satisfies P and is still unreachable. To show a state is reachable there is exactly one move, and it’s the one you made above — exhibit a path q₀ ↦ s₁ ↦ ⋯ ↦ s.

This is the 8-puzzle argument with smaller numbers. There the invariant is the parity of the inversion count, and it proves the famously unreachable configuration unreachable without examining a single one of the 181 440 states you can get to.

3

A potential function proves the game ends

Termination is a separate obligation from correctness — the course splits them deliberately, and partial correctness is the name for what you get if you only do the invariant half. The tool for the other half is a potential function (also called a derived variable): a function that assigns a number to every state. It isn’t part of the state and the machine never looks at it — you compute it from the state, so you can watch how it changes along each transition.

The potential function here counts empty cells. The whole termination proof is three lines:

1 · define e : states → ℕ,  e(s) = the number of – entries in b. At the start, e(q₀) = 9. 2 · decreases every transition fills exactly one empty cell, so s ↦ t implies e(t) = e(s) − 1 < e(s). That makes e strictly decreasing. 3 · conclude a sequence of natural numbers can’t decrease forever. Along any play the values go 9, 8, 7, …, so there are at most 9 transitions before a final state.

Both ingredients matter. The values have to live in ℕ (or anything else with no infinite descending chain), and the decrease has to be strict on every transition. The widget below breaks the second one.

Under the place-on-top rule e is still a perfectly good potential function — it’s just only weakly decreasing (covering a mark gives e(t) = e(s)), and weakly decreasing proves nothing about termination. The variable didn’t break. The proof broke, and the machine really does have infinite runs, so no repair is possible. That’s the honest order to think in: the argument fails first, and then you go looking for whether the claim was ever true. (The §2 invariant goes too: an X covering an O raises #X and lowers #O, so #X − #O jumps by 2.)
Check

Why does the potential function e prove the game ends?

Put the two halves together and you have the full statement. Termination: every play reaches a final state within 9 transitions. Partial correctness: a final state is either a board with a line (someone won) or a full board with none (a draw) — which is just the contrapositive of the transition rule, since any other state has an empty square and no line, hence a transition out.

The short version

  1. Put everything in the state. If the transition rule needs to know it, it belongs in the tuple — here, whose turn it is. A machine that consults the history isn’t a machine.
  2. A final state is one with no transitions out. Don’t add a “game over” flag. Restrict the transition relation and let the winning boards have nothing to go to.
  3. Prove preserved, then cite the Invariant Principle. Preserved is a one-line check per transition type; true at q₀ is usually immediate. The Principle does the rest.
  4. An invariant is a proof of impossibility. P failing means unreachable. P holding means nothing — for reachability you must exhibit a path.
  5. A strictly decreasing, ℕ-valued potential function proves termination. Weakly decreasing isn’t. And the starting value is your step bound: e(q₀) = 9, so at most 9 moves.

Water jugs, Die Hard style
