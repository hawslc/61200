Tic-tac-toe is a state machine

States, transitions, an invariant, a potential function — on a game you already know.

1

A state is the board + whose turn it is

state s = (b, p): board b is a 3×3 tuple of X / O / –, and p ∈ {X, O} moves next. example ( X–––O–––X , O ) q₀ ( ––––––––– , X ) s ↦ t No line yet → p marks any empty cell; turn passes. Line → no transitions. final state No outgoing transitions. Reach one and the play has terminated.
Why must p be in the state?
Without it, the rule can’t tell whose mark goes next — you’d need the move history, and a state machine only sees the current state.
Is every pair reachable?
No. A board of nine X’s is a perfectly good pair, but play never produces it. Telling those apart is §2’s job.

2

An invariant rules boards out, never in

P(s) (#X = #O  ∧  p = X)  ∨  (#X = #O + 1  ∧  p = O)
  • ✓ True at q₀: 0 = 0, X to move.
  • ✓ Preserved: each move adds one mark and passes the turn.
  • ⇒ Invariant (Invariant Principle). P fails ⇒ unreachable.
Proof that P is preserved
Suppose P(s) and s ↦ t. If p = X: #X = #O, X is added, O is next → #X = #O + 1, p = O. If p = O: #X = #O + 1, O is added, X is next → #X = #O, p = X. Either way P(t).

3

A potential function proves the game ends

Potential function (aka derived variable): a number computed from each state.

1 · define e(s) = number of – cells.  e : states → ℕ,  e(q₀) = 9. 2 · decreases s ↦ t  ⇒  e(t) = e(s) − 1  — strictly. 3 · conclude ℕ can’t decrease forever ⇒ ≤ 9 transitions to a final state.
Why both ℕ-valued and strict?
ℕ has no infinite descending chain, so a strict decrease on every transition has to stop. Drop either condition and the argument fails — the widget below drops strictness.

What else breaks?
The machine really can run forever, so no other potential function will rescue it. The §2 invariant goes too: X covering O changes #X − #O by 2.

Why does e prove the game ends?

The full claim: termination + partial correctness
Termination: every play reaches a final state within 9 transitions. Partial correctness: a final state is a win or a full board — any other state has an empty cell and no line, so it has a transition out.

The short version

  1. State = everything the next move needs. Board + turn. No history.
  2. Final state = no transitions out. No “game over” flag needed.
  3. Preserved + true at q₀ ⇒ invariant. That’s the Invariant Principle.
  4. Invariants rule out, never in. For reachability, show a path.
  5. Strictly decreasing ℕ-valued potential ⇒ termination. Its start value bounds the steps.
