Tic-tac-toe is a state machine

The 8-puzzle gets the lecture. Here is the same apparatus — states, transitions, a preserved predicate, a derived variable — on a game you already know the rules of, so the only new thing is the machinery.

1

A state is the whole board, not the last move

The temptation is to call “X plays the centre” a state. It isn’t — it’s a transition. A state has to carry everything the next transition needs to know, and that means the full board and whose turn it is.

squares 123456789 Numbered row by row, left to right. Every board on this page uses these numbers. B the set of boards: all functions b : {1, …, 9} → {X, O, ·}. b(i) is what sits on square i; · means empty. We write b row by row, e.g. XX· / ·O· / ···. Q Q ≔ B × {X, O}. A state is a pair s = (b, p): the board, and the player p who moves next. Nothing else — no move history, no score. |Q| = 3⁹ · 2 = 39 366. q₀ q₀ ≔ (b∅, X), where b∅(i) = · for every i. The single start state. won(b) true iff some line ℓ has b(i) = X for all i ∈ ℓ, or b(i) = O for all i ∈ ℓ. The 8 lines are {1,2,3}, {4,5,6}, {7,8,9}, {1,4,7}, {2,5,8}, {3,6,9}, {1,5,9}, {3,5,7}. s ↦ t (b, p) ↦ (b[i ≔ p], p) for each square i with b(i) = ·, and only when ¬won(b). There are no other transitions.
b[i ≔ p] is the board that agrees with b everywhere except square i, which now holds p. p is the other player: X = O, O = X.

Q is deliberately generous. It contains the board with nine X’s, boards where both players have a line, boards where it’s X’s turn with X two marks ahead. Putting a pair in Q makes no claim that play can get there — sorting that out is what §2 is for.

That last clause is the whole design. Winning doesn’t trigger anything; it just leaves you in a state the transition rule has nothing to say about. In state-machine vocabulary the state is stuck, and a play that reaches it has terminated.

The state tuple is doing real work. Drop p from the state and the transition relation stops being well defined — you’d have to look at the history to know whose mark goes down next, and a state machine is not allowed to look at history. Everything it knows, it knows because the state says so.
2

An invariant rules boards out, never in

Here is the predicate. For a state s = (b, p), write #X and #O for the number of each mark on b:

P(s) (#X = #O  ∧  p = X)  ∨  (#X = #O + 1  ∧  p = O)

P is preserved. Suppose P(s) and s ↦ t. Either p = X, in which case #X = #O and the transition writes one X and hands the turn to O, giving #X = #O + 1 with p = O — the second disjunct. Or p = O, in which case #X = #O + 1 and the transition writes one O and hands back, giving #X = #O with p = X — the first disjunct. Either way P(t).

And P(q₀) holds: 0 = 0 and p = X. So by the Invariant Principle, P is an invariant — true at every reachable state. Which gives you the thing invariants are for: any state where P fails is unreachable, and you never had to search.

The asymmetry is the point. An invariant can only ever prove unreachability. When P fails, you are done — no reachable state looks like that. When P holds, you have learned nothing: the third board above satisfies P and is still unreachable. To show a state is reachable there is exactly one move, and it’s the one you made above — exhibit a path q₀ ↦ s₁ ↦ ⋯ ↦ s.

This is the 8-puzzle argument with smaller numbers. There the invariant is the parity of the inversion count, and it proves the famously unreachable configuration unreachable without examining a single one of the 181 440 states you can get to.

3

Counting empty squares proves the game ends

Termination is a separate obligation from correctness — the course splits them deliberately, and partial correctness is the name for what you get if you only do the invariant half. For the other half you need a derived variable: a function from states to ℝ that behaves predictably along every transition.

e(s) the number of squares with b(i) = ·.  e(q₀) = 9, and e(s) ∈ ℕ always.

Every transition fills a square that was empty, so s ↦ t gives e(t) = e(s) − 1: e is strictly decreasing and ℕ-valued. There is no infinite strictly decreasing sequence in ℕ, so no play runs forever — and since e(q₀) = 9, every play is stuck after at most 9 transitions. You get the bound for free, out of the same argument.

Under the slide rule e is still a perfectly good derived variable — it’s just only weakly decreasing, and weakly decreasing proves nothing about termination. The variable didn’t break. The proof broke, and the machine really does have infinite runs, so no repair is possible. That’s the honest order to think in: the argument fails first, and then you go looking for whether the claim was ever true.
Check

Why does e prove the game ends?

Put the two halves together and you have the full statement. Termination: every play reaches a stuck state within 9 transitions. Partial correctness: a stuck state is either a board with a line (someone won) or a full board with none (a draw) — which is just the contrapositive of the transition rule, since any other state has an empty square and no line, hence a transition out.

The short version

  1. Put everything in the state. If the transition rule needs to know it, it belongs in the tuple — here, whose turn it is. A machine that consults the history isn’t a machine.
  2. Terminal means stuck, not special. Don’t add a “game over” flag. Restrict the transition relation and let the winning boards have nothing to go to.
  3. Prove preserved, then cite the Invariant Principle. Preserved is a one-line check per transition type; true at q₀ is usually immediate. The Principle does the rest.
  4. An invariant is a proof of impossibility. P failing means unreachable. P holding means nothing — for reachability you must exhibit a path.
  5. Strictly decreasing and ℕ-valued is the termination argument. Weakly decreasing isn’t. And the starting value is your step bound: e(q₀) = 9, so at most 9 moves.
